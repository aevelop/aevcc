## Strategy

The NEXUS framework documents defining the 7-phase pipeline, coordination protocols, scenario runbooks, and activation resources.

### NEXUS Master Strategy (`strategy-nexus-strategy.md`)

The authoritative 1,100+ line operational framework defining the complete NEXUS pipeline architecture, command structure, agent coordination matrix across 9 divisions (40+ agents), handoff protocols, quality gates, and three deployment modes (Full/Sprint/Micro). Establishes the philosophical foundation that individual agent excellence must be coordinated through structured phases and evidence-based quality checkpoints.

### Executive Brief (`strategy-executive-brief.md`)

C-suite SCQA (Situation-Complication-Question-Answer) formatted overview communicating NEXUS business value: 40-60% timeline compression, 80% reduction in production defects. Provides clear recommendations with ownership, timeline, and expected outcomes for rapid executive comprehension and stakeholder buy-in.

### Quick Start (`strategy-quickstart.md`)

5-minute activation guide with mode selection matrix, ready-to-copy activation prompts, agent roster at-a-glance, and scenario-based activation paths. Bridges strategic documentation and tactical execution for practitioners launching NEXUS pipelines.

### Phase 0 - Discovery (`strategy-phase-0-discovery.md`)

3-7 day intelligence phase where 6 agents conduct parallel market research, user analysis, technology assessment, and regulatory scanning. Validates the opportunity before committing resources with a GO/NO-GO/PIVOT decision gate kept by the Executive Summary Generator.

### Phase 1 - Strategy (`strategy-phase-1-strategy.md`)

5-10 day phase where 8 agents define system architecture, brand identity, technical specifications, financial planning, and sprint prioritization before writing code. Produces the Architecture Package all downstream work depends on with dual gate-keeper authority (Studio Producer + Reality Checker).

### Phase 2 - Foundation (`strategy-phase-2-foundation.md`)

3-5 day phase where 6 agents build the technical skeleton (CI/CD, infrastructure, design system, database). Two parallel workstreams (Infrastructure vs. Application) compress timeline. Every developer gets a working environment, deployable pipeline, and design system upon completion.

### Phase 3 - Build (`strategy-phase-3-build.md`)

The longest phase (2-12 weeks) with the core Dev-QA loop quality mechanism. Four parallel tracks (Core Product, Growth & Marketing, Quality & Operations, Brand & Experience) compress timeline by 40-60%. The Agents Orchestrator manages all loops, escalations, and maximum 3 retry attempts before escalation.

### Phase 4 - Hardening (`strategy-phase-4-hardening.md`)

3-7 day intensive quality phase where the Reality Checker defaults to "NEEDS WORK" and requires overwhelming evidence for READY. Five agents collect comprehensive evidence, three analyze it, then Reality Checker cross-validates everything to prevent premature production deployment.

### Phase 5 - Launch (`strategy-phase-5-launch.md`)

2-4 week go-to-market phase with launch sequence periods: T-7 (pre-launch), T-0 (launch day), T+1 to T+7 (post-launch), T+7 to T+14 (optimization). Marketing agents fire in concert with engineering monitoring through blue-green deployment and real-time metrics dashboards.

### Phase 6 - Operate (`strategy-phase-6-operate.md`)

Ongoing phase with no end date establishing operational cadences (continuous, daily, weekly, monthly, quarterly). Implements the continuous improvement loop: Measure-Analyze-Plan-Build-Validate-Deploy. Can re-activate NEXUS-Sprint or NEXUS-Micro for new features. Targets 99.9% uptime SLA.

### Agent Activation Prompts (`strategy-agent-activation-prompts.md`)

40+ copy-paste ready prompts for activating any agent in any NEXUS role. Each prompt includes context, deliverable requirements, reference documents, and quality expectations. Dramatically reduces onboarding time and ensures consistent agent activation patterns.

### Handoff Templates (`strategy-handoff-templates.md`)

Seven standardized templates (Standard, QA Pass, QA Fail, Escalation, Phase Gate, Sprint, Incident) preventing context loss between agents. Each template includes required fields, evidence requirements, and next-action clarity.

### Scenario: Startup MVP (`strategy-scenario-startup-mvp.md`)

Compressed 4-6 week NEXUS-Sprint runbook for startup MVPs. Combines Discovery + Architecture into Week 1, Core Build into Weeks 2-3, Polish into Week 4, Launch into Weeks 5-6 with 18-22 lean agent roster.

### Scenario: Enterprise Feature (`strategy-scenario-enterprise-feature.md`)
