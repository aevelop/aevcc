# MCP Servers

Source of truth (regenerated by `scripts/export.sh`; secrets -> `${PLACEHOLDER}`, home -> `$HOME`):

- [mcp-servers.json](mcp-servers.json) -- 19 user-scope servers (`~/.claude.json` -> `mcpServers`)
- [mcp-servers-project.json](mcp-servers-project.json) -- local-scope servers, keyed by project path

## Install (user scope)

```bash
export GITHUB_PERSONAL_ACCESS_TOKEN=ghp_...   # github
export FIRECRAWL_API_KEY=fc-...               # firecrawl
export STITCH_X_GOOG_API_KEY=...              # stitch (X-Goog-Api-Key header)
export HEADED=false                           # playwright, optional
bash scripts/install/60-mcp.sh
```

Unset placeholders are passed empty with a warning. Fix later: `claude mcp remove -s user <name>`, set the var,
re-run -- or edit `~/.claude.json`.

Manual equivalents (note: `-e` / `-H` go after the name/url):

```bash
claude mcp add -s user -t http cloudflare-docs https://docs.mcp.cloudflare.com/mcp
claude mcp add -s user github -e GITHUB_PERSONAL_ACCESS_TOKEN="$GITHUB_PERSONAL_ACCESS_TOKEN" -- npx -y @modelcontextprotocol/server-github
claude mcp add -s user -t http stitch https://stitch.googleapis.com/mcp -H "X-Goog-Api-Key: $STITCH_X_GOOG_API_KEY"
```

## Servers

| Name | Type | Auth / edit before use |
| ---- | ---- | ---------------------- |
| github | stdio | `GITHUB_PERSONAL_ACCESS_TOKEN` |
| firecrawl | stdio | `FIRECRAWL_API_KEY` |
| filesystem | stdio | path arg `$HOME/Documents/GitHub` -- change in the json |
| obsidian | stdio | vault arg `$HOME/Desktop/Page-Fixes/test-obsidian` -- change in the json |
| supabase | stdio | replace `--project-ref=YOUR_PROJECT_REF` |
| memory, sequential-thinking, magic, notebooklm, playwright, railway | stdio | none (`HEADED` optional for playwright) |
| vercel, clickhouse, cloudflare-docs, cloudflare-observability, cloudflare-workers-bindings, cloudflare-workers-builds | http | OAuth on first use via `/mcp` |
| stitch | http | header `X-Goog-Api-Key` |
| serena | stdio | none; needs the `serena` CLI on PATH (step 00: `uv tool install -p 3.13 serena-agent`, then `serena init`) |

`serena` ([oraios/serena](https://github.com/oraios/serena), 1.7.0) gives the agent symbol-level find / references /
rename / edit through a language server. Registered with `--context=claude-code --project-from-cwd`, so the
directory Claude starts in is the active project (each project gets a `.serena/` folder with `project.yml` and
memories; gitignore it or commit it per project). Global config `~/.serena/serena_config.yml`: the reference machine
sets `web_dashboard_open_on_launch: false` so no browser tab opens per session (dashboard still at
http://localhost:24282/dashboard/ while a session runs; port goes up by one per extra instance). Do not install Serena from a plugin marketplace (maintainers warn
those listings are stale). Optional, not applied: Serena's `serena-hooks` for settings.json and the
`claude --system-prompt="$(serena prompts print-cc-system-prompt-override)"` launch that counters Claude Code's
bias toward built-in Grep/Read; see <https://oraios.github.io/serena/02-usage/030_clients.html#claude-code>.

## Local scope (per project dir, what the reference machine uses; not auto-installed)

```bash
cd <project>
claude mcp add -t http figma https://mcp.figma.com/mcp
claude mcp add playwright -- npx @playwright/mcp@latest
claude mcp add trigger -- npx trigger.dev@4.4.5 mcp --dev-only
claude mcp add notebooklm -- npx notebooklm-mcp@latest
```

Use `-s project` instead to commit an `.mcp.json` into the repo.
