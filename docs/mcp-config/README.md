# MCP Servers

Source of truth (regenerated by `scripts/export.sh`; secrets -> `${PLACEHOLDER}`, home -> `$HOME`):

- [mcp-servers.json](mcp-servers.json) -- 22 user-scope servers (`~/.claude.json` -> `mcpServers`)
- [mcp-servers-project.json](mcp-servers-project.json) -- local-scope servers, keyed by project path

## Install (user scope)

```bash
export GITHUB_PERSONAL_ACCESS_TOKEN=ghp_...   # github
export FIRECRAWL_API_KEY=fc-...               # firecrawl
export STITCH_X_GOOG_API_KEY=...              # stitch (X-Goog-Api-Key header)
export HEADED=false                           # playwright, optional
bash scripts/install/60-mcp.sh
```

Unset placeholders are passed empty with a warning. Fix later: `claude mcp remove -s user <name>`, set the var,
re-run -- or edit `~/.claude.json`.

Manual equivalents (note: `-e` / `-H` go after the name/url):

```bash
claude mcp add -s user -t http cloudflare-docs https://docs.mcp.cloudflare.com/mcp
claude mcp add -s user github -e GITHUB_PERSONAL_ACCESS_TOKEN="$GITHUB_PERSONAL_ACCESS_TOKEN" -- npx -y @modelcontextprotocol/server-github
claude mcp add -s user -t http stitch https://stitch.googleapis.com/mcp -H "X-Goog-Api-Key: $STITCH_X_GOOG_API_KEY"
```

## Local scope (per project dir, what the reference machine uses; not auto-installed)

```bash
cd <project>
claude mcp add -t http figma https://mcp.figma.com/mcp
claude mcp add playwright -- npx @playwright/mcp@latest
claude mcp add trigger -- npx trigger.dev@4.4.5 mcp --dev-only
claude mcp add notebooklm -- npx notebooklm-mcp@latest
```

Use `-s project` instead to commit an `.mcp.json` into the repo.
