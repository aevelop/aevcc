# Claude Code CLI + Tools

Reference versions: [versions.txt](versions.txt) (regenerated by `scripts/export.sh`).

## Install

```bash
# Node >= 22 first (nvm): https://github.com/nvm-sh/nvm
curl -fsSL https://claude.ai/install.sh | bash       # Claude Code, native installer -> ~/.local/bin/claude
brew install jq gh tmux ffmpeg                        # jq: scripts | gh: git workflows | tmux: dev-server hook | ffmpeg: hyperframes skills
npm install -g agent-browser intelephense typescript typescript-language-server prettier markdownlint-cli @alibaba-group/open-code-review
```

Or: `bash scripts/install/00-cli.sh`

## Verify

```bash
claude --version && node -v && jq --version && gh --version | head -1
```

## Notes

- `intelephense` -> `php-lsp` plugin. `typescript-language-server` -> `typescript-lsp` plugin (the reference
  machine had the plugin enabled but no server installed; the script installs it).
- `@alibaba-group/open-code-review` (`ocr` CLI) -> `open-code-review` plugin (`/open-code-review:review`).
- `agent-browser` -> `agent-browser` skill. `ffmpeg` -> hyperframes video skills.
- `bun` is present on the reference machine (`.claude/package-manager.json` says bun) but nothing here requires it.
- Other npm globals in `versions.txt` (gemini-cli, shopify, eas, mjml, ...) are project tools, not Claude Code setup.
- Login: run `claude` once. `gh auth login` for GitHub.
